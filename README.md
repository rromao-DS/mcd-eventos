# MCD Eventos

Plataforma para operar eventos de grande porte: convocação, aceite, formulário, alocação por área e liderança, assinatura de 3 documentos por trabalhador, fechamento de folha e entrega à contabilidade.

Regra central: **Intermitentes** e **Funcionários do Evento** são módulos independentes por evento e nunca se misturam.

## Estado atual

Fase de produto e UX/UI, com protótipo navegável em dados fictícios. Não há backend, Google Drive, envio de mensagens nem assinatura com validade jurídica.

## Estrutura

- `docs/kit/`: kit de requisitos (comece por `00_COMECE_AQUI.md`).
- `dados/08_DADOS_DE_EXEMPLO.json`: dados fictícios para o protótipo.
- `prototipo/`: protótipo navegável (em construção).

## Segurança

Não versionar capturas de tela com credenciais, logos sem autorização nem dados reais de trabalhadores.
